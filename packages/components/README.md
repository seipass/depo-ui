# @depo-ui/components

Reusable React components for Depo UI, including actions, forms, navigation, data display, selection, feedback, disclosure, and overlays.

Product applications should normally import components from `@depo-ui/react`:

```tsx
import '@depo-ui/react/css';
import { Button, Card } from '@depo-ui/react';
```

This package is a public lower-level integration point for design-system consumers. Its stylesheet includes the primitive, foundation, and token CSS chain.
