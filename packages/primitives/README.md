# @depo-ui/primitives

Small layout and DOM primitives used by Depo UI components, such as `Box`, `Stack`, `Grid`, `Text`, and `Heading`.

This is a public lower-level integration point. Its stylesheet includes the foundation CSS chain:

```css
@import '@depo-ui/primitives/css';
```

Product applications should generally import React components from `@depo-ui/react`.
