# Accessibility

Depo UI targets WCAG 2.2 AA. Accessibility is designed with the Component Contract and verified alongside interaction, theme, responsive, and content behavior; it is not a post-implementation layer.

## Baseline

- Use semantic HTML before ARIA and expose an accurate accessible name, role, state, and value.
- Keep keyboard order, focus-visible indication, focus entry, and focus restoration predictable.
- Test dark, light, high-contrast, forced colors, reduced motion, 200% text resize, 400% zoom, and reflow.
- Test long text, CJK, RTL, localization, and error recovery rather than only the default English fixture.
- Use automated Axe checks as a defect detector, never as proof that a Component is fully accessible.

The repository-level checklist and known manual-review limitations live in `testing/accessibility/`. The formal contract lives in `specs/foundations/accessibility.md`.

## Complex interactions

Combobox, Dialog, DataGrid, Tree, Menu, and Command Palette require manual screen-reader review, focus-recovery evidence, and browser keyboard tests in addition to automated checks.
