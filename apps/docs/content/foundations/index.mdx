# Foundations

Foundations are the stable vocabulary behind every Depo UI Component. The implementation consumes Semantic tokens, while Reference and Component tokens remain inside their defined boundaries.

## Token layers

```text
Reference → Semantic → Component
```

Reference values describe a palette or scale. Semantic values describe a role such as `color.bg.canvas`, `color.fg.primary`, or `color.action.primary`. Component aliases are private to the Component that owns them.

The generated token manifest provides the dark appearance used by every Depo UI surface. Use [Examples](/docs/examples) to inspect density, direction, long content, and CJK behavior without changing the appearance.
